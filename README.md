# 🚀 Team Task Manager

A full-stack web application for managing team projects and tasks with secure authentication and role-based access control.

🌐 **Live Demo:**  
[TaskFlow Live Demo](team-task-manager-production-2321.up.railway.app)

---

# ✨ Features

## 🔐 Authentication
- Secure Signup/Login system
- JWT-based authentication
- HTTP-only cookies for enhanced security
- Password hashing using bcrypt

## 📁 Project Management
- Create and manage projects
- Track project progress
- Organize tasks efficiently
- Manage project members

## ✅ Task Management
- Create, edit, and delete tasks
- Assign tasks to team members
- Set priorities and due dates
- Update task statuses

## 👥 Team Management
- Invite members via email
- Assign user roles
- Remove members from projects

## 📊 Dashboard
- View assigned tasks
- Track overdue tasks
- Get project summaries at a glance

## ⏰ Overdue Task Tracking
- Automatically identifies overdue tasks
- Helps teams stay on schedule

## 🔑 Role-Based Access Control

| Role | Permissions |
|------|-------------|
| **Admin** | Manage members, edit projects, create/update/delete tasks |
| **Member** | View projects/tasks and update task status |
